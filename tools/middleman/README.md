# Middleman

acts as a local websocket proxy + message inspector

## usage

```bash
cd tools/middleman
cargo run
````

by default:

* proxy binds on **127.0.0.1:8766**
* web UI served on **127.0.0.1:8080**
* target backend is **ws://127.0.0.1:8765/ws** or **wss://..** 


[http://127.0.0.1:8080](http://127.0.0.1:8080)
